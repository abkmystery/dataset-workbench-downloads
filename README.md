# Dataset Workbench for Windows

Download the [Windows executable](https://github.com/abkmystery/dataset-workbench-downloads/releases/download/v0.2.0-preview.2/DatasetWorkbench.exe) and open it. The portable build runs on Windows x64 and requires no installer.

Dataset Workbench prepares training and holdout data on your computer. See the [Workbench page](https://aidata.skasit.com/workbench) for supported inputs and the preparation steps.
